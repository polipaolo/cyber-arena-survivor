# Cyber Arena Survivor

Browser game 2D arcade in stile "survivor" ambientato in un'arena neon futuristica.
Un unico file `index.html` con HTML, CSS e JavaScript integrati: nessuna dipendenza, nessuna installazione.

## Come giocare

Apri `index.html` nel browser (Chrome, Edge o Firefox).

| Tasto | Azione |
|---|---|
| WASD / Frecce | Muoviti |
| Mouse | Mira |
| Click sinistro | Spara (se lo sparo automatico è disattivato) |
| Spazio / Shift / Click destro | Scatto invulnerabile |
| P / Esc | Pausa |
| M | Muto |
| F | Attiva/disattiva sparo automatico |
| 1 · 2 · 3 | Scegli il potenziamento al level-up |

## Caratteristiche

- Ondate infinite di nemici: droni, tank, kamikaze esplosivi, tiratori e il boss Overlord
- 15 potenziamenti con rarità (Sparo Triplo, Proiettili Rimbalzanti, Scia di Fuoco, Drone Alleato, Calamita XP, Lame Orbitanti, Arco Voltaico...)
- Screen shake, hit-stop, slow motion, particelle, numeri di danno e griglia reattiva
- Effetti sonori e musica procedurali con Web Audio API
- Record salvato nel browser

## Pubblicazione con GitHub Pages

1. Carica i file in un repository GitHub.
2. Vai su **Settings → Pages**.
3. In **Source** scegli il branch `main` e la cartella `/ (root)`, poi salva.
4. Dopo un minuto il gioco sarà online su `https://<tuo-utente>.github.io/<nome-repo>/`.
